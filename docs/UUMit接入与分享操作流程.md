# 用 UUMit 从手机访问笔记随行

以下菜单名称以 v1.0.8 为参考。读取器和演示笔记都保留在电脑上，UUMit 提供远程访问入口。

## 添加本地应用

1. 按 [快速上手说明](../README.md#第一次运行) 启动读取器，先在电脑浏览器确认 `http://127.0.0.1:4317` 可以打开。
2. 在 UUMit 客户端选择「开始连接」，在网页登录、核对连接码并确认绑定这台电脑。已绑定的电脑可以跳过这一步。
3. 在 UUMit 里选择「发布应用」→「本地应用」，使用以下配置：

   | 配置项 | 填写内容 |
   | --- | --- |
   | 显示名称 | 笔记随行，或你自己取的名字 |
   | 本机地址 | `127.0.0.1` |
   | 本机端口 | `4317` |
   | 应用类型 | 网页应用 |

4. 保持「这个应用能操作这台电脑」关闭。添加后在「谁能用」里选择「只有我」，复制 UUMit 为这次配置生成的应用网址。

## 用手机验证

1. 手机关闭 Wi-Fi，使用移动网络打开刚复制的应用网址，登录和电脑绑定的同一个 UUMit 账号。
2. 展开笔记目录，搜索「本地服务」，打开笔记并查看图片。
3. 在电脑的 `demo-vault` 中添加一篇示例笔记，在手机上点击「刷新」，再搜索这篇笔记。
4. 用未登录 UUMit 的窗口检查访问限制。页面、目录、正文和图片的新请求都应被拦截。

## 邀请或收回访问

需要给指定的人看时，在「谁能用」中选择「邀请的人」，从「成员与邀请」生成邀请链接。请用另一个账号实际验证接受邀请和移除成员后的访问结果。邀请范围是整个读取器，受邀者可以查阅其中的笔记和图片。

在权限验证完成前保持私密访问。收回访问时可移除成员、切回「只有我」或停用应用。确认撤销是否生效时，以对方发出的新请求为准。已经被保存的截图和内容仍会留在对方设备上。

日常使用时，电脑需要开机并联网，读取器服务和 UUMit 客户端都需要保持运行。电脑里的副本更新后，在手机上点击「刷新」即可。
