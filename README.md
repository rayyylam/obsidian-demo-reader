# 笔记随行

一个在电脑上运行的只读 Markdown 笔记阅读器，适合浏览从 Obsidian 导出的笔记副本。打开网页即可按目录浏览、搜索标题和正文、跳转内部链接，也可以调整正文字号。

## 第一次运行

1. 安装 Node.js 22.12 或更新版本，并在终端运行 `node -v` 确认已安装。
2. 下载并解压本项目，或者克隆本项目。用终端进入包含 `package.json` 的项目目录。
3. 安装依赖并启动：

   ```sh
   npm ci
   npm start
   ```

4. 在电脑浏览器打开 [笔记随行](http://127.0.0.1:4317)。自带示例笔记，打开后可以先搜「本地服务」。

以后在项目目录执行 `npm start` 即可。在启动终端按 Control+C 可以停止服务。macOS 用户安装依赖后也可双击 `启动笔记随行.command`。如果系统拦截双击启动，使用终端命令即可。

## 试读自己的 Obsidian 笔记

1. 在 Obsidian 的仓库管理器里查看所选仓库在电脑上的位置，然后在 Finder 或文件资源管理器中打开它。
2. 选出愿意让访问者看到的 `.md` 笔记及相关图片，把副本复制到本项目的 `demo-vault/我的笔记/`。首次使用可自行创建「我的笔记」文件夹。保留子目录结构和相对路径，让链接和图片能找到对应文件。
3. 回到阅读器点击「刷新」，新笔记就会出现在目录里。以后修改了原笔记，需要重新复制副本，再点击「刷新」。

侧栏的「演示知识库」显示读取位置 `./demo-vault`，这是相对于项目文件夹的位置。读取器固定读取这个目录。复制笔记时请跳过 `.obsidian`、隐藏文件和符号链接。

支持 Markdown、Obsidian 内部链接（如 `[[笔记名]]`）以及使用 Markdown 相对路径引用的 PNG、JPEG、WebP 图片。外部图片和原生 HTML 不会加载。阅读器提供浏览和搜索，笔记编辑仍在 Obsidian 或文本编辑器中完成。

## 在手机上打开

默认只在运行读取器的电脑上访问。需要从手机远程打开时，可以自行配置 UUMit。详见 [UUMit 接入说明](docs/UUMit接入与分享操作流程.md)。电脑、读取器和 UUMit 客户端需要保持在线，手机看到的是电脑上 `demo-vault` 的当前内容。

## 常见问题

- **页面打不开。** 查看启动终端是否有报错。若提示 4317 端口已占用，先打开本地地址检查读取器是否已经启动。
- **新笔记没出现。** 确认副本位于项目内的 `demo-vault`、扩展名为 `.md`，再点击「刷新」。
- **图片没出现。** 确认图片副本也在 `demo-vault` 内，并检查笔记里的相对路径。Obsidian 的 `![[图片名]]` 嵌入语法可以改成标准 Markdown 图片写法，如 `![说明](../附件/图片.png)`。
